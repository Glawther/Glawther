# Glawther Soares

Desenvolvedor de software no Brasil, formado em Desenvolvimento de Sistemas.
Escrevo código principalmente em Python e JavaScript, com foco em automação de mídia, APIs e machine learning aplicado.

Atualmente mantenho o [Dark_print](https://github.com/Glawther/Dark_print) (automação de vídeos verticais com FastAPI e FFmpeg), o [CrawlMesh](https://github.com/Glawther/CrawlMesh) (motor distribuído de web scraping e monitoramento de preços) e o [FraudGuard](https://github.com/Glawther/FraudGuard) (motor antifraude em tempo real para PIX e cartão com explicabilidade SHAP).

---

## Projetos

| Projeto | O que faz | Tecnologias |
| :--- | :--- | :--- |
| [FraudGuard](https://github.com/Glawther/FraudGuard) | Motor de análise de risco e antifraude em tempo real para PIX e Cartão com explicabilidade SHAP, consulta de BIN, reputação de ASN/Shodan e câmbio ao vivo. | Python, FastAPI, HTTPX, SQLite, PostgreSQL, Redis, Docker |
| [CrawlMesh](https://github.com/Glawther/CrawlMesh) | Infraestrutura distribuída de web scraping, conversão de HTML para Markdown limpo e monitoramento de preços com rotação de fingerprints, circuit breaker de proxies e rate limiter por domínio. | Python, FastAPI, HTTPX, BeautifulSoup4, Redis, PostgreSQL, Docker |
| [Dark_print](https://github.com/Glawther/Dark_print) | Produção e publicação automática de vídeos curtos a partir de pautas e roteiros, com acervo de mídia em domínio público, efeitos sonoros e legendagem dinâmica. | Python, FastAPI, MoviePy, FFmpeg, Streamlit |
| [EDX Digital](https://github.com/Glawther/edx-digital) | Gestão de clientes e vendas com captura de leads por webhook e ambiente conteinerizado. | JavaScript, Node.js, Firebase, Docker |
| [Classificador de Risco de Crédito](https://github.com/Glawther/classificador-risco) | Modelo de crédito com Random Forest e árvore de decisão para explicar o caminho de cada classificação. | Python, Flask, scikit-learn, Graphviz |
| [Previsão de Preços de Ações](https://github.com/Glawther/Preditor_de_valor) | Painel de regressão com retreino automático e histórico de versões dos modelos. | Python, Flask, scikit-learn, MLflow |
| [Radar de Preços](https://github.com/Glawther/Radar-de-Pre-os) | Comparador de preços com varredura em 30 lojas brasileiras e avisos de queda de valor. | Python, Streamlit, SQLite |
| [Calendário de Aventuras](https://github.com/Glawther/calendario-aventuras-react) | Planejador de atividades com login, filtros por status e publicação automatizada. | React, Vite, Firebase, GitHub Actions |
| [Dashboard de Vendas](https://github.com/Glawther/dashboard) | Painel comercial com indicadores diários, gráficos e mapa de calor de pedidos. | Python, Django, Chart.js |
